# Example limitations

These are illustrative Luuna contracts, not observed executions. The check result uses synthetic hashes for schema validation; it is not evidence that Go tests ran. Project command recipes are incomplete examples and must be confirmed for actual repositories. Candidate and plan outlines deliberately use replacement markers so they cannot be mistaken for an approved executable plan.

The three JSON schemas cover the project, check-result, and event examples. Cross-record semantic checks, path resolution, DAG validation, permissions, approval hashing, and all remaining domain schemas belong to M0 implementation.
