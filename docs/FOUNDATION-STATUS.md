### Established and not established

Established on Linux with a genuine provider: an approved real writer in a Luuna-owned worktree; required host checks bound to the exact candidate and executed before any review; a fresh, separately identified Pi reviewer whose structured verdict the runtime enforces (`passed` → `reviewed`; `changes_required`/`blocked` → `paused`; invalid or self-inconsistent output → `failed`, never `reviewed`); manual repair reusing the immutable approval to create r2 with fresh evidence; bounded automatic repair stopping at `max_attempts`; cancellation and hard-kill recovery with reaped children and conservative spend reservation; developer checkout untouched; no credential value in any artifact.

Observed provider behaviour, recorded rather than hidden: `gpt-4.1` passed every check in one run; the smaller `gpt-4o-mini` and `gpt-4.1-mini` violated the reviewer JSON contract in 2 of 5 feature reviews; the runtime failed those candidates closed. Recovering from such a failure currently requires a new candidate revision through repair, because `validate` only resumes `pending` or `interrupted` candidates. That is safe but costs a writer attempt for a candidate whose checks passed; allowing a fresh validation generation for a candidate with passed checks and no recorded verdict is proposed for the MVP usability gate, not changed here. `python -m unittest -v` output is not recognised by the test-count heuristic (`tests_detected: null`); the pass/fail decision still comes from the exit code, and the empty-suite guard does not apply to that runner. Baseline runs leave `__pycache__` untracked in the developer checkout, as recorded for M2b. The reviewer's own transcript is not persisted; only `review.started`, the verdict, findings and evidence are.

Not established: native Mac/Windows client launch and service lifecycle (no capable host here); any provider other than OpenRouter; model behaviour beyond the three models above. M3's provider exit is closed on Linux; M3 as a whole closes only with the native-host evidence.
