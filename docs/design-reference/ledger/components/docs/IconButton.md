IconButton is a square, icon-only button for toolbars and the top bar.

Consumer provides `icon`, `label` (required: becomes the tooltip and the accessible name), `onClick`, and optionally `variant="filled"` (round accent, e.g. the top-bar create button), `active` (toggled tools such as dictation) or `dot` (unread notifications).

- 32px square, 18px icon in ink-muted, fill on hover.
- Never use an icon-only button for a destructive action.
