PageHeader puts the page title, optional breadcrumbs and description, and the page's actions in one compact block at the top of the content.

Consumer provides `title`, optional `breadcrumbs` (a Breadcrumbs), `description` (one sentence), `badge`, and `actions` (at most one primary Button plus one or two secondary or a Menu).

- Title and actions share one row so the primary content starts within roughly 120px of the top of the content area.
- Keep the description to one line; longer explanations go in an Accordion or the docs.
- Never place an image, hero or promotion inside the header.
