Callout is an inline, dismissible tip inside a page.

Consumer provides the message as `children`, optional `icon` (default bulb), `action` + `href`, and `onDismiss` (pass `false` for a permanent callout).

- surface-muted ground, ink-muted text, no border and no coloured edge.
- One sentence. Lead with the benefit, put the verb in the link ("Manage currencies").
