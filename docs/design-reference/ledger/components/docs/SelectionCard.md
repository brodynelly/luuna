SelectionCard shows text captured from another app, its source and how long Insert stays available.

Consumer provides `text`, `sourceApp`, `expiresIn` (seconds, from the 10-minute capture lifetime), `canPaste`, `onClear`.

- Header names the source app; the countdown or a "Copy only" badge explains whether Insert will work.
- Shows the 6,000-character limit; never truncates the selection.
