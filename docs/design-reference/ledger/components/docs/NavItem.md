NavItem is one row in the sidebar; NavItem.Group gives a set of rows an overline label.

Consumer provides `label`, `icon`, `href`, `active` and optional `trailing` (`"plus"` to create, `"chevron"` to expand).

- 32px rows, 18px icons in ink-muted; the active row turns label and icon accent-text and bold. No filled pill for the active state.
- Group labels use the `overline` style in sentence case ("Products").
