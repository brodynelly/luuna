Kbd renders a keyboard shortcut as key caps; ShortcutHint pairs it with a label.

Kbd: `keys` as an array (`['Ctrl','Alt','Space']`) or a `+` string. ShortcutHint: `label` and `keys`.

- Use the platform's names: Ctrl / Alt / Shift on Windows, ⌘ / ⌥ / ⇧ on macOS.
- Show shortcuts in menus, settings rows and empty states — not in body copy.
