EmptyState fills a list, table or page that has no content yet, and offers the next step.

Consumer provides `title`, optional `icon`, `description`, `action` (Buttons) and `bordered` (default true).

- Title states the fact ("No files match", "No downloads yet"); the description says how to get content; one primary action at most.
- For charts use MetricCard's built-in "No data" state.
