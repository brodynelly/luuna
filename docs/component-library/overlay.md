# Feedback and overlays (`packages/ui/src/overlay/`)

ADR 0034 family 4. Native elements first, no third-party code, Ledger tokens only. Barrel: `overlay/index.ts`. Sheets, in layer order: `overlay/overlay.css`, `overlay/feedback.css` (layer `components`). All classes carry the `ov-` prefix. Existing `Callout`, `ErrorBanner`, `Loading`, `ProgressBar`, `NoticeRegion` and `ContextMenuArea` are unchanged; notices stay untimed and there is no timed toast. `.notice` follows Mantine's Notification metrics (`specs/mantine-component-metrics.md`): `--surface-raised` ground, 1px `--separator` border, `--radius-md`, `--shadow-lg`, 10px block and end padding, 14px text, no coloured side accent; the entrance is the existing `toast-in` and there is no exit animation.

Rules that hold for the whole family:

- Modal surfaces (`Dialog`, `Drawer`) use the native `<dialog>` and `showModal()`. They never open on load, have **no exit animation** (close is instant), one entrance animation (the existing `dialog-in` and `scrim-in` keyframes, backwards fill), and a press on the backdrop does not close them. Reduced motion removes the entrance.
- The owner controls `open`. Escape fires the native `cancel` event, which is prevented and routed to `onClose`; the owner sets `open` to `false`. Focus returns to the opener on close.
- Floating panels (`Popover`, `Menu`, `Tooltip`) are not modal. They are placed by `placement.ts` (DOM-free, flips at the viewport edge, clamps inside it) and positioned through the `--float-x` and `--float-y` custom properties, never an inline `style`.
- Tone is a prop typed from `../tone/tone`. Colour comes from the `data-tone` indirection in `components.css`; the shape is the shared `.tone-mark`; the text is the caller's.
- No colour-only meaning, no coloured left border, no gradient, no blur. `className`, `data-*` and aria props pass through to the outer element.

Helpers (DOM-free, unit-tested): `placement.ts` (`placeFloating`, `chooseSide`, `clamp`), `menuNav.ts` (roving index, type-ahead, key to action), `modalState.ts` (guarded `showModal`, focus restore, cancel), `tooltipGate.ts` (hover and focus gating), `floating.ts` (the one DOM edge for placement, tested with plain objects).

Not verified here: the tests render with `react-dom/server` and exercise the helpers with fakes, because the workspace has no DOM environment (no jsdom). Real `showModal()` focus trapping, Esc routing, focus return, flip placement, the entrance animation and forced-colors rendering need the real WebView.
