# Data display (`packages/ui/src/data/`)

Presentational components for tables, lists, facts, metrics, timelines, logs, board columns and accordions. They render what they are given: no runtime rule, bulk-action policy or tone mapping lives here. Status chips always go through `StatusBadge`. Every component forwards `className`, `data-*` and `aria-*` props to its root element. Sheets: `data/data.css`, `data/table.css` (layer `components`). Nothing here animates; the only motion is a row-hover colour step on tokens.

Exports (`data/index.ts`): `DataTable`, `Pagination`, `PropertyList`, `ListRow`, `ListGroup`, `MetricCard`, `Timeline`, `EventLog`, `BoardColumn`, `Accordion`, `sortRows` (stable in-memory sorter, empty values last) and the prop and item types. Existing `Table`, `Facts`, `StatTile` stay untouched and are migrated per screen later.

Not decided here: which rows exist, their order, what a selection permits, or what a tone means. The caller supplies sorted rows and runtime words.
